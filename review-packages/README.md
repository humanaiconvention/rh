## Evidence and reproduction

Each package contains unchanged Lean sources, explanatory documentation, exact assumptions, dependency information, a build recipe, attribution and notices. Each self-excluding `PAYLOAD-MANIFEST.json` fingerprints its other files. Existing six-package payloads are preserved; their assembly records retain their original dates and verification limits.

The additional API sources use public-safe `EVIDENCE.json` maps. They contain source and retained-record hashes, successful-run metadata, and the exact accepted terminal axiom lines. Private raw logs, machine paths, source-development provenance, runtime diagnostics and rejected recovery reports are excluded. These curated records are not fresh compiler transcripts. All twenty-five primary saved reports for these added API sources use only `propext`, `Classical.choice`, and `Quot.sound`.

The new `DEPENDENCIES.json` and `DEPS.json` files list the complete declared pinned project package sets and each local source/import boundary. Fixed Git revisions identify source trees. They do not certify a binary artifact-producer closure or a new per-module import-graph replay. Proposed portable locks and Lake files still require actual acceptance in a legitimately provisioned environment.

Read `BUILD.md` before any replay. Dependency acquisition, configuration work, compiler admission and actual build processes require their own scope and resource accounting. No compilation, dependency provisioning or workflow dispatch was performed for this batch. The older [finite-ledger certificates](../qrh-obstructions-lean/README.md) remain a separate project.

## Mathematical and review scope

The cumulative and polynomial APIs package classical mathematics into explicit reusable formal interfaces. The counting companion separates arbitrary-linear-order prefix bounds from supplied polynomial root witnesses; its degree-exhaustion helpers overlap the sign-witness interface, and no interoperability bridge is claimed. Their application hypotheses remain obligations. The Jensen package retains its two positive measures and exact Gaussian conditions; it does not assert a native/Jordan instantiation. The theta package includes the complete infinite-source and normalization chain. The power-transport package adds an actual-source application of the coordinate comparison to every natural power; it includes the needed providers, with 162 supporting reports reused from other packages and excluded from the new primary-report count. None of the added interfaces supplies an unresolved global arithmetic estimate.

Existing repository MIT notices and separate Mathlib Apache-2.0 notices are retained unchanged. Imported dependencies keep their own terms. Each `ATTRIBUTION.md` and `LICENSE-STATUS.md` records pending contributor, rights and API decisions without inventing historical model identities. Owner-authorized hosting of these review snapshots is distinct from a final endorsed release or upstream submission.

Preparation was AI-assisted. Internal checks are not external independent review. No claim of current-upstream absence or mathematical priority is made. Only the curated payloads are included; no private archive or operational infrastructure is part of the collection.
